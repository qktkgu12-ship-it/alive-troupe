이번에 바뀐 것

  • 얼굴과 장소의 자리를 맞바꿨습니다 — 레퍼런스처럼 제목 다음에 얼굴들이 오고, 맨 아래 줄에 장소(왼쪽)와 D-day(오른쪽)가 나란히 섭니다.
  • 명단 크기를 일정방 리스트에 맞췄습니다 — 아바타 28px, 이름 14px로 앱 안에서 같은 리듬이 됩니다.
  • 얼굴들을 흰 알약에 담았습니다 — 추가 인원(+N)도 같은 알약 안에 들어갑니다. 프로필은 모두 원형입니다.
  • 카드 탭과 펼치기를 나눴습니다 — 본문은 지금 배포된 대로 일정 페이지로, 펼치기는 우상단 버튼만. (일정 상세 페이지는 나중에)
  • 펼치면 폭까지 넓어집니다 — 옆 카드가 화면 밖으로 밀려나 상세에만 집중하게 됩니다.
  • 펼치기 버튼 색을 뒤집었습니다 — 접혔을 땐 흰 버튼이라 눈에 띄고, 펼치면 반투명으로 물러납니다.
  • 참석이 기본으로 눌려 있습니다 — 팀원이거나 지정 인원이면 이미 참석 상태입니다.

불참을 고르면

바텀시트가 올라와 사유를 묻습니다. 등록하면 문구가 불참으로 등록됐어요로 바뀌고, 명단에서 내 이름이 불참 쪽으로 옮겨가며 사유가 이름 옆에 붙습니다. 다시 참석을 누르면 사유와 함께 원래대로 돌아갑니다.

정해진 것

  • 카드 본문 탭 = 일정 페이지(지금 배포된 동작 그대로), 펼치기 = 우상단 버튼만. 카드 아무 데나 눌러 보시면 어디로 가는지 안내가 뜹니다.
  • 불참 사유는 전원에게 공개합니다.
  • 명단 크기는 일정방 만들기의 개별 참여인원 리스트와 동일하게 맞췄습니다 — 아바타 28px, 이름 14px.

다음에 할 것

  • 확정 일정 만들 때 참여 인원 선택창 — 일정방 만들기의 참여인원 선택과 똑같이 만들고, 카드에는 거기서 고른 인원이 뜨게 합니다. (다음 작업)
  • 일정 상세 페이지 — 카드 탭이 갈 전용 화면. 지금은 일정 페이지로 갑니다.
  • 참여 신청 저장 위치 — 팀원이 아닌 사람의 신청은 새 저장소와 보안 규칙이 필요합니다.
